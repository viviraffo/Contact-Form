# ✉️ Modern Contact Form

Ein stilvolles und funktionales Kontaktformular, das zeigt, wie man Benutzereingaben strukturiert und visuell ansprechend gestaltet.

## 🌟 Features
- **Benutzervalidierung:** Nutzung von HTML5-Attributen (`required`, `type="email"`), um korrekte Eingaben sicherzustellen.
- **Modernes Design:** Einsatz von `linear-gradient` Hintergründen und fließenden Übergängen.
- **Interaktive Elemente:** Hover-Effekte auf dem Submit-Button für besseres Nutzerfeedback.
- **Responsive Layout:** Das Formular passt sich dank flexibler Breitenangaben (`width: 80%`) verschiedenen Displaygrößen an.

## 🛠️ Technologien
- **HTML5:** Einsatz von Labels, verschiedenen Input-Typen und Textareas für optimale Barrierefreiheit.
- **CSS3:** Fokus auf Layout-Design, Abstände (Padding/Margin) und visuelle Effekte wie Farbverläufe.
